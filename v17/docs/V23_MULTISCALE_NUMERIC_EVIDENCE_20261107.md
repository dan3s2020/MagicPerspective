## 1. Exact original solution shape and numeric extinction

The original `Discoverer.shape` from V17/V22 remains byte-for-byte untouched. It propagates a goal potential using its original factor `0.97` and ignores relaxations below `1e-12`. Controlled source tests with the same long chain show full direct paths at 900 steps, but no complete shape at 920, 1,000 and 3,000 steps even with verified connected edges.

`multiscale-grounded-hypermaze.mjs` implements a hierarchical, compositional interpretation of **the SAME original function**, on observed event/action edges, recursively grouping up to 128 child transformations per node. The original `shape()` is called separately for each scale; outputs are joined **before the first physical step**. No substitution with BFS, beam search, next-byte prediction or external target-answer oracle.

**Independent native CI:** 100,000 known-event transformations across 6,877,784 input characters; all original subshapes linked, complete predicted route, then **100,000/100,000** individual independent world-physics confirmations; only 790 original shape invocations and at most 129 states per invocation, recursion depth 2. Hierarchy does not imply arbitrary length is mathematically guaranteed, but the measured 920-step extinction is demonstrably bypassed.

## 2. Unknown *answer* rather than answer supplied as goal

The earlier V22 `goal.slots` examples already contained desired tokens. This **new** controlled benchmark requires the question only to identify the entity and ask for the value **after all observed events**. Its terminal-time condition seeds the original attraction: the correct final value is **NOT** in `goal.slots`, nor in a reference string available to the planner.

Three observed action-syntax families plus 8 observed question instances gave 300/300 unseen location answers (11,237,882 cumulative input characters, largest 7,703 token text) and a 118,882-token world with a 100-event trace. Every answer was frozen before independent execution.

## 3. Numeric text: even the FINAL ANSWER is not written in the input

`learned-numeric-causal-shape.mjs` fits numeric state transformations to **complete independent before/action/after observations**. It learns word-slot grammar templates from witnessed text/physical triples and estimates action effects from the transparent candidate basis `[x,q,x*q,1]`. This basis is a designed inductive bias, not a universal spontaneous discovery.

With 120 independent physical action samples, the learner identified five verified coefficients, in grammar-observation order:

| Empirically identified effect | `[x, q, x*q, 1]` coefficients |
|---|---|
| Receive units | `[1, 1, 0, 0]` |
| Spend units | `[1, -1, 0, 0]` |
| Scale by variable quantity | `[0, 0, 1, 0]` |
| Reverse with quantity | `[-1, 1, 0, 0]` |
| Reset to quantity | `[0, 1, 0, 0]` |

The model then solved **300/300** independent heldout mixed-operation text questions, with the final numerical answer generated by composing learned effects. The independent evaluator uses its own ground-truth step physics and checks every action. Source input total: 2,434,838 characters.

The longest numeric test starts at `712345`, consumes **100,000** new genuine textual action descriptions across **4,800,055** input characters, and predicts the complete final number **1,212,341** before acting. That number's literal string is absent from the observed document and the question. The independent physical evaluator then accepts the whole 100,000-step path and confirms the same value. This is a controlled arithmetic task, not an OpenThoughts benchmark.

## 4. Negative controls, limits and honesty

The tests require removing learned rules/question templates to cause **abstention**, an independently physically rejected action to **stop** without false success, and contradictory location reports to **abstain**. Unknown nonlinear action physics does not pass the fitted affine+biproduct law threshold. Checkpoint JSON roundtrips preserve learned state. Original V17 maze parity and existing V19/V21 tests remain intact.

**Unresolved:**
- The text grammars are represented in the witnessed training set; the learned effects use an explicitly designed 4-feature mathematical basis. A novel syntax or effect outside this family is not generally solved.
- Procedurally generated long inputs are **not** freely written, heterogeneous, externally sourced natural language or independent OpenThoughts3 heldout answer tasks. We have **no evidence** for 100% arbitrary text/math.
- The V23 motors are independent added research source modules; the original V17 live answer-producing `Brain`, `AligningGraph`, CUDA training pipeline, checkpoint and existing page are **not yet causally linked** to their predictions. No GPU training, speed target or real UI live act/replan result is claimed.
- This exact hierarchy demonstrates length extension over a numeric threshold but not autonomous dimension discovery, physically proved 5D space, emergent general intelligence or a solution to all science.
- The full historical Verbatim repository audit is still incomplete; missing bytes cannot be certified.

## 5. Failure and correction evidence

The first new numeric CI run [#42342233021](https://github.com/dan3s2020/MagicPerspective/actions/runs/42342233021) correctly failed **test assumptions**: JavaScript distinguishes `-0` from `0` with strict deep equality, and a naïve text substring assertion could confuse digits in the heldout entity ID with a numeric answer. The source now canonicalizes learned zero coefficients, and test entities contain alphabetic-only IDs, preventing this false leak signal. [Full green run #42342352414](https://github.com/dan3s2020/MagicPerspective/actions/runs/42342352414) proves these corrections and preserved original regression tests.
