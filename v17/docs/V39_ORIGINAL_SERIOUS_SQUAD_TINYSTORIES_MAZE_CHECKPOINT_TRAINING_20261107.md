# MagicPerspective V39 — serious native **one-Brain** SQuAD + maze + TinyStories experience

Research branch `experiment/V39-ORIGINAL-UNIFIED-SERIOUS-TRAIN-20261107`, 2026-11-07. **No main merge, no replacement of the user's historic Brain, no unsupervised 100%-general-language claim.**

## What actually trains in the SAME persistent original Brain

This implementation forks the verified V34 ORIGINAL V17 native training architecture (same `Brain`, `Discoverer`, `NoiseAgency`, `observedTransformations`, XD atlas and serialized `.v8`), then PORTS the V38 validated `NativeRealTextEvidencePaths` source **verbatim**. It saves exactly ONE new isolated `brains/brain-0.v8` for these combined lessons:

1. **Original 2D maze / desired-state attraction:** `playExercise(makeMaze(...),brain.disc)` with up to 145 genuine deterministic maze-world episodes and the original `Discoverer.shapeGraph`. The native learning must reach a minimum goal attraction/conductance before QA.
2. **Genuine Unicode TinyStories SOURCE text:** streamed directly from the existing local `TinyStories-train.txt` in fixed raw UTF-8 bytes, separated by authentic `<|endoftext|>` markers. Each observed story is fed to the original `brain.observedTransformations.observeText(story)`; actual observed sentence and learned operator counts are saved inside THE SAME `Brain.v8`. Byte offset, story count, duplicates/rejections and percentage of the full source file consumed are all shown. UTF-8 decoding is strict and stops on bad byte sequences, never inserts `?`. The in-memory native active indexed-state window is the original bounded `maxObserved=12000`, not an infinite storage promise. The original CUDA/6-scale byte-sequence weight training is **not** performed in V39's story lane. This is explicitly reported, not silently replaced.
3. **Real human-written question-to-source-goal preference:** the exact **V38** supervised real evidence scoring and original `shapeGraph` path, with training only on authentic original SQuAD v1.1 TRAIN answers and gold offsets that refer to actual substrings. It does not ask `AligningGraph.write` to fabricate a reference. Original V38 does not use a new pretrained GPT or embedding model.
4. **Time-averaged sparse evidence weights within the same saved Brain:** each 200 actual QA exposures after exposure 400 (up to 23 snapshots for 2,400 x 2), preserving both last and average learned weights. Model selection uses **500 internal article-disjoint TRAIN** questions; **650 official external DEV questions** are parsed/evaluated ONLY AFTER the policy is frozen and checkpointed. SHA256 of DEV is pinned beforehand without parsing gold answers. Same original `.v8` stores the selected policy, running sums and snapshot count, source progress cursor, QA exposure counter, actual human evidence, maze action knowledge and TinyStories transformations. No label enters the original inference path.
5. **NO automatic overwrite:** existing original source file is NEVER modified. A separate output directory may be resumed ONLY if a V39 manifest exists and the exact source hashes/parameters/source-file identity match. Checkpoints use original Brain.save temp-file/atomic rename, and ongoing `v39-training-atlas.jsonl` is append-only.
6. **Responsive separate local training monitor** at `127.0.0.1:8909`, with real status, progress bars, actual QA examples/s, source bytes consumed, frozen validation and DEV scores; Pause/Resume/Save commands. The historic V17/V34 UI is not edited. Control calls need the browser's local session token; unknown/control-less calls are refused.

## Launching (only AFTER all acceptance checks pass)

The isolated PowerShell launcher is `v17/START_V39_SERIOUS_TRAINING.ps1`. It requires `-OriginalBrain <ACTUAL_EXISTING_V17_V34_BRAIN.v8>`, because a trained source checkpoint cannot be invented by a script. For example, use the known previously mentioned `D:\MagicPerspective-FULL-ATLAS\v17\runtime-hypermaze-real\brains\brain-0-winner.v8` ONLY if `Test-Path` on the user's computer confirms it. An output such as `D:\MagicPerspective-V39-SERIOUS` is independent of the historical run. Use `-Download` to fetch the official SQuAD JSON files safely.

Typical settings: 2,400 TRAIN examples per epoch, two epochs, 500 TRAIN article-disjoint calibration questions, 650 external DEV questions, checkpoints every 100 examples, average snapshot every 200 exposures after 400, and up to 2,000 genuine TinyStories observations sampled from existing raw text. These are defaults, not invented evidence of dataset-scale 100%.

The launcher runs in **explicit CPU Node.js mode for V39's QA/TinyStories observed-rule components**. It does NOT invoke or claim original V17 CUDA training loops, and does not benchmark the RTX 3050 Ti. The existing V34 CUDA launchers remain untouched and can run separately on their original unmodified dedicated checkpoints; do not write to the same V39 `.v8` concurrently from another process.

## Honest remaining blockers — required for a future complete release

- This is a **real serious research-training runner**, not a demonstrated general unlimited natural-language solver. An actual human-source extractive benchmark of 121/650 exact still leaves 529/650 whole answers wrong. Prior independent OpenThoughts3 long-form Q/A remains unproven. Zero "intelligence %" is invented; UI shows task-specific heldout accuracy only.
- The V39 trainer's raw-story lane updates **observed Unicode transformation memory**, NOT the full V17 CUDA `AligningGraph` or all 5D causal/world actions. The supplied source Brain keeps its previous learned nodes/noise/xD, but future text learning in this lane does NOT train every historical neural/generative subsystem.
- The experimental original V36 goal-inference task learner, V37 failure-analysis overlays and V38 averaged QA learned features are separate branches; V39 currently integrates V38 with the V34 original multi-world Brain, not V36's separate task-intent memory. No universal single architecture convergence is claimed.
- Real NVIDIA 3050 Ti CUDA performance and the 1.92 GB full TinyStories run are not proved by GitHub CPU CI; a user's local hardware integration test remains necessary. Never call CPU tests "real CUDA benchmark."
- At most the requested number of genuine TinyStories source documents is consumed, not every byte of a 1.92 GB dataset by default. The progress bar reports **actual raw source byte offset / total file size**.
