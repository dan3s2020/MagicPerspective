## 3. Two especially relevant scientific limitations discovered outside this branch

### 3.1 What really blocks correct human text answers?
V37 exact frozen human SQuAD forensics:
- 450 previously unseen human questions from distinct DEV articles, after training 2,400 original TRAIN questions in V35. Raw exact **62/450**; normalized exact **65/450**.
- Correct candidate in retained graph for **394/450** questions; only **56** lacked the correct canonical candidate. **329** had a correct candidate but ranked it below an incorrect answer. Original seeded attraction approximately constant across candidate terminals, while a supervised evidence preference controlled ranking. More nodes alone cannot repair 329 ranking failures.
- Gold was used ONLY in a separate **post-frozen forensic** routine, not for route planning or training on DEV. Document distinction: source availability, answer candidate validity, semantic preference, independent causal transformation, and actual physical transition must not collapse into one “path exists” boolean.
- Related V30 real OpenThoughts3 source demonstrates **0/4** real unseen complete answer, and V37 notes independent **0/24**; remain hard counterexamples to "we already solved general text."

### 3.2 Winnowing solves lexical bridge detection but NOT semantic transport
V30 original motif sampling approximately 1-in-32 could omit short repeated phrases simply by absolute alignment. V32 builds deterministic rightmost-minimum winnowing over observed whole-token k-grams, fingerprints from exact SHA256 of complete underlying token spans, and episode-SHA protected SQLite. This is useful for selecting which **real** historical observations the same original Brain should revisit instead of O(all-history) scans. **Not yet integrated here**. Integration proposal must preserve source-only status and not promote repeated source hash to a verified state-action transition without before/after physical evidence.

## 5. Architecture hypotheses and test plan for the next genuine proof
1. **Single causal core:** each world yields witnessed (state, action, next state, context, provenance) tuples, not assumed semantic edges; keep physical/observed/inferred/lexical labels distinct.
2. **Full source retention vs bounded planning:** complete input bytes + historical episodes in immutable atlas; learned operator graph as a persistent database; dynamic query frontier must report true budgets and unknown edges. A 50000-state cap is not whole language.
3. **Axis/geometry discovery:** infer node-local transport from independent before/after evidence, test if 5D/ND alignment changes *actual unseen output*, use shuffled axes/zero-noise/foreign-source/short-window controls. Merely rotating colored nodes or moving a temperature slider is not proof.
4. **Cross-document path transfer:** use only independently witnessed repeated transformed contexts, compare a state where a needed edge is unlearned/evicted, then learn from old observations and measure genuine first-shot change. Do not include answer in goal except for explicitly goal-specified tests.
5. **Task-conditioned goal:** human novel question + context must induce a valid answer criterion before answer is known. V37 suggests candidate ranking is a more important bottleneck than merely unbounded graph expansion.
6. **State/history aliasing:** preserve hidden context, noncommuting action order and stochastic outcomes; reject shortcuts that have not been physically verified; let feedback-triggered replan respond to actual world deltas.
7. **Scale/full original GPU/UI:** first resolve Windows `EPERM fsync` and actual checkpoint resume; then measure real RTX training on user corpus and retained original TinyStories brain, full GUI parities and data consumption progress, stopping on real errors.
8. **Open source and verbatim:** preserve entire tested branch and user statement history including inaccessible gaps; never manufacture an all-green result from tests run on different engines.

**Current proof status:** meaningful verified controlled maze/text transformation results exist; independent human-language and real OpenThoughts results remain incomplete or low; no single universal original-native long-answer first-shot 100% engine has been demonstrated.
