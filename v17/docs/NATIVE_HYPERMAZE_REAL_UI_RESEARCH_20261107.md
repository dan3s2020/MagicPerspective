# MagicPerspective: original native V17 text-world hypermaze UI — verified research, NOT release

## Scope and protection

The user requested the **SAME original V17 organism** that first predicts an entire maze path before moving, not a new next-character model, synthetic demo or assistant-substituted architecture. This standalone visualizer retains the exact existing `v17/transcend/torus-aether/ui/index.html` and `magic.html` unchanged. It does not modify main, original trained TinyStories `.npz`, saved `.v8`, or previous project branches.

- **Real page:** `v17/transcend/torus-aether/ui/native-hypermaze.html`
- **Real renderer:** `v17/transcend/torus-aether/ui/native-hypermaze.js`
- **Actual source model:** `v17/transcend/torus-aether/devour/brain.mjs` and unchanged original `worlds/exercise.mjs::Discoverer.shape`, generalized in `Discoverer.shapeGraph` using the same original actual learned potential propagation.
- **Original worker:** `v17/transcend/torus-aether/devour/worker.mjs` (opt-in `--native-hypermaze`, otherwise original worker behavior preserved).
- **Server graph:** `POST /native-hypermaze?w=N&start=<original-observed-text>&required=<comma-separated-goal-tokens>&execute=1&topology=1`. The target reference answer is NOT a field or training observation.
- **Original controls:** `POST /control?do=start|pause|save&w=N` (same worker, without any separate fake GUI simulator).
- **Original telemetry:** `GET /graphs`, with real actual `nativeHypermaze.actualCorpusRows` (not fake throughput).

## What is visualized, entirely from the original Brain

- Each **state** is a complete original tokenized and rendered observed-operator-reachable text state; source labels are actual text, not fictional placeholder phrases.
- Every **edge** is generated by an exact `ObservedTransformations` original learned edit effect, including action kind, word change, index and observed support. These are *internal learned text-world actions*, not externally verified semantic actions.
- Every **potential** is the value field computed by the original `Discoverer.shapeGraph` attraction/conductance propagation.
- Every **phase** is the real original Geometry 5D torus coordinate of an observed state, or a learned original action's signed coordinate displacement for an unseen state, as labeled in the response. For missing coordinates the canvas uses an explicitly labeled, non-learned topology layout.
- The **golden line** is the complete globally predicted path *frozen before the first body action*. The **cyan line** is the actual recorded local body execution; `frames` expose selected learned actions, before/after states, noise, goal and correction.
- No reference answer, second worker, externally hard-coded path or synthetic scoring is used by the visualization. It shows failure/no path truthfully.
- The standalone UI permits rotating the 5D projection, selecting dimensional axes, zooming, selecting the real worker, pausing/saving/starting it, setting an explicit goal and animating the actual returned frames.
- Chrome smoke tests use a URL with user-supplied `source`, `required` and `plan=1`. The resulting graph is still calculated by the ORIGINAL worker, never preprogrammed in HTML or JS.

## Crucial limitations that must remain visible in the UI and docs

1. Text-as-hypermaze learned effects and goal propagation demonstrate **STRUCTURED** composition only. They do not derive a unique correct answer to arbitrary natural-language questions or prove 70–100% first-try final semantic correctness.
2. The explicit required target-token constraints are supplied by the task; automatic semantic goal discovery is **not implemented**. A globally predicted path to a user-supplied goal is not a predicted answer to an unknown goal.
3. Ablating the 5D geometric preference or transferable path policy changed **zero of 100** controlled final outputs; neither has independently measured causal benefit on task correctness. Independent real-world noise intervention benefit remains unproved.
4. Native `ObservedTransformations` retains `maxTokens=256` and `maxObserved=12000` working limits. The original AligningGraph still has historical ASCII processing. No all-byte permanence beyond the bounded work model is demonstrated.
5. Real original end-to-end NVIDIA CUDA throughput, trained two-million TinyStories checkpoint migration, OpenThoughts unseen semantic benchmark, and mathematical universal proof remain **NOT TESTED/NOT PROVEN**.
6. **Production release is BLOCKED** by `v17/research/text-hypermaze/production-release-gate.mjs --gate`; a research CI success does not lift this gate. No full-user launch command is authorized.
