What is real—and what is not

This is a replay of a verified isolated experiment, not a live connection to the currently running MagicPerspective server. Its source nodes and code fragments come from the actual Git-verified V17 text engine. Its exploration controller is newly added; it is not yet a native trained V17 suborganism.

The noise portal is a learned exploratory jump in the code graph, not a physical portal or a higher dimension.

SHA256 of the original source is recorded in the experiment manifest. No source files, current V17 runtime, or checkpoints were overwritten.
