Falsifiable test and remaining gap

Invariant tested: renaming the observed entities must commute with the learned action transformation. Changing the action mapping without recalibration must break predictions. Neither condition requires the goal path to be shown during calibration.

Not yet built: learned world encoders and projections, non-isomorphic transformations, free-form sentence understanding, shared trainable latent transitions, cross-domain performance advantage, or connection to the original V17 maze checkpoint.
