## Original code preserved, actual changes

- The existing original V17 \`Discoverer.shape()\` remains the authoritative baseline. Its existing graph-neighbor extension remains in place for the isolated original graph, with tested parity on the 2D maze. The core scalar update and default 2D path were not changed in this revision.
- Added \`multipath.mjs\` to analyze **observed graph** adjacency, count exact shortest action sequences using reverse BFS + BigInt dynamic programming, and compute discounted successor **goal occupancy** for a fixed uniform edge-choice policy.
- The optional SR path only changes decisions when original scalar-field neighbor values TIE; original field stays the primary decision. Logs unchanged vs changed routes and number of ties. It does NOT claim that SR counting = exact shortest path counting.
- Added a backward-compatible optional \`loopPenalty\` / \`loopWindow\` to original V17 \`AligningGraph.write()\`. With no penalty it remains byte-for-byte original. When enabled for frozen evaluation, repeated generated byte n-grams have candidate weights downranked. Does not create goals or prove semantic understanding.
- Original corpus \`train.mjs\` still reads actual \`D:\training\OpenThoughts3-1.2M\` Parquet training rows, trains original V17 Brain on them and learns original V17 maze world through lived episodes. On frozen HELD-OUT rows, compares original native shape, optional SR tie, lexical-only retrieval, original free character generation and loop-resistant character generation. Saves exact shortest-path counts, candidate branches, F1, exact answer matches, output repetition and no-leakage checks.
- PowerShell launcher \`START_NATIVE_LANGUAGE_PATHS.ps1\` invokes source-parity tests and refuses to synthesize a corpus.

## Acceptance criteria and falsification

1. Original 2D maze behavior and \`Discoverer.shape\` 2D/graph parity pass.
2. On a branching graph, exact shortest routes are 4, while discounted successor occupancy is higher for the branch with 3 good outgoing paths than the branch with 1; original scalar field ties. The original remains available to compare.
3. A graph with no goal must yield no fabricated goal path; cycles must not inflate the *shortest* path count.
4. Original \`AligningGraph.write\` with no optional penalty must return identical bytes. Penalty should be tested with real candidate alternatives; no guaranteed general improvement is claimed.
5. F1 and exact correctness on withheld natural language may be **zero or below lexical retrieval**. Such a result is NEGATIVE evidence for a general transfer claim, not a reason to relabel retrieval as semantic reasoning.
6. With \`-Strict\`, fail the run if the hybrid's measured F1 does not exceed *all* baselines. Without \`-Strict\`, report outcomes faithfully.

## Open research gaps

- Question/answer links are engineered lexical cues, not a learned causal semantics topology.
- Goal nodes are marked TRAINING answers. The held-out correct answer is never used to form the plan. Goal reachability alone is NOT correctness on unseen prompts.
- A policy-conditioned successor representation estimates occupancy; it does NOT count all paths and is not quantum interference.
- The ZIP's amplitude/quantum work is a separate simulated experiment, not a hardware result and NOT inserted into this original V17 algorithm.
- The archived ZIP's 900 vs 1,024-step horizon finding comes from a Python reimplementation and must not be presented as a tested new branch without running the original source's corresponding conditions.
- No end-to-end general semantic maze transfer, original V17 CUDA speedup or real RTX GPU run has yet been established by this integration.
