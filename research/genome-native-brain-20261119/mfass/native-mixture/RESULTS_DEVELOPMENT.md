## Measured results on 150 separate gene/exon groups (2,490 authentic variants)

| Method | Average Precision, primary | AUROC | Genuine splice disruptions ranked among the first 100 |
|---|---:|---:|---:|
| Source random-rate selection | **0.03695** prevalence | 0.5 expected | 3.695 expected |
| Original native Brain C self-selected automatically `class:1` | **0.09634** | 0.67693 | **17** |
| Original native single calibrated perspective `exact:175` | **0.15227** | 0.71814 | **22** |
| Source-only TRAIN empirical region+splice-boundary+REF→ALT original 0/1 counts | **0.16561** | **0.75024** | **19.44** expected under ties |
| Original native five-entry MULTI-PERSPECTIVE after genuine source CALIBRATION | **0.21970** | 0.73084 | **28** |
| Same original native multi-perspective selection against deliberately shuffled calibration labels | **0.12083** | 0.70116 | **21** |

- This is a **44.3% RELATIVE increase in DEV Average Precision** from best original single C mask0.15227 to original native mixture0.21970, with SAME original Brain, DNA input, source assay training examples and A organ. Absolute gain +6.74 percentage points AP.
- Compared to the simple source-only empirical control, the genuine native original mixture is +5.41 AP percentage points (~+32.7% RELATIVE) on these group-heldout **DEVELOPMENT** samples, plus ~8.56 more top100 expected real disruptions under tie-aware comparison.
- The shuffled-label mixture AP0.12083 fails to match the genuine outcome-calibrated mixture AP0.21970, an important falsifiable negative selector control. This helps but is not by itself proof of independent external reproducibility.
- Its AUROC0.73084 remains BELOW the empirical control0.75024 despite higher AP: the improvement is specifically in **ranking rare high-effect variants**, not uniform classification quality over all false-positive rates.
- The predeclared check showed a single native `c.top` belief reproduced the single active native C readout EXACTLY (maximum absolute score error0), so improvement does not come from accidentally replacing the original predictor.

**Important limitations:** source group-separated internal DEV was examined in previous projects; it is not a virginal independent external validation. The native input contains only local4nucleotide REF context (plus ALT, position and region) of actual original170nt genomic constructs. Researcher-designed source calibration objective is external to native Brain's original automatic self-selection. The original Gene/exon grouping avoids same local source gene between cohorts but has not proven genome-family-homology disjointness. MFASS is an in-vitro splicing reporter rather than clinical patient RNA.
