# Original V42 C8 data-alphabet equivalence: 120 candidate names ≠ 120 independent perspectives

2026-11-23. **Source-level mechanistic audit**, NOT a new performance measurement. No original code or running native checkpoint was changed.

## Evidence from the actual source code and authentic source distribution

- Original `v17/transcend/epistemic-text/engine.mjs` constructs candidates with kinds `exact`, `fold` and `class` for each nonzero binary C-history mask; the MFASS calibrated experiment preregistered only `exact/fold`.
- Original `v17/transcend/torus-aether/lean-c.mjs` computes a native key by concatenating `feature(ctx[i], p.kind)` at positions set in the mask, and updates **both** original programs from the **same** true training outcome at every native C.observe event.
- For `fold`, ASCII uppercase `A..Z` maps deterministically to lowercase; lowercase letters and digits are unchanged. Thus it is a bijection between the symbol alphabets used at EACH fixed position in these authentic MFASS 8-symbol windows.
- Original MFASS stimulus positions have fixed and disjoint kinds: `[E/U/D (uppercase), a/b/c/d/e (lowercase), 0/1/2/3 (digit), A/C/G/T × 5 (uppercase nucleotide)]`. **No position mixes uppercase and lowercase representations of the same biological symbol.**
- For any fixed mask, `exact:mask` and `fold:mask` therefore partition ALL possible source-legal MFASS windows identically. Their counter tables receive the same outcomes at the same positions and their learned output distributions are mathematically equal on the source-legal domain (the key strings differ but are in one-to-one correspondence).
- This means the preregistered **120 exact/fold native C candidate names encode at most 60 distinct biological information masks**, unless a source-domain input violation is discovered. This is NOT a statement that the original C masks are equivalent to each other: different masks still access different real REF/ALT and gene-position variables.

## Scientific consequences

A naively selected top-K native `LeanC.top` ensemble can include both `exact:mask` and `fold:mask` and effectively count the same underlying information twice. This can produce a valid change in **mixture weights** but does **not** constitute access to two independent perspectives. Extra nominal candidate count is not an additional information dimension.

The currently running [separately pre-committed native mixture study](./PRETEST.md) is left unchanged, including its 120 nominal candidates and its exact, blinded biological calibration. Its selected mask set must be inspected after actual completion, and any claimed discovery must distinguish duplicate weights from genuinely complementary source-variable masks.

A subsequent **distinct causal hypothesis** would require a prior frozen source-motivated intervention: one original representative per exact/fold mask and a physically meaningful diversity constraint (e.g. include authentic region and authentic splice-boundary distance in independent native masks), compared to identical-size duplicate-allowed controls. This hypothetical is **NOT yet an executed test** here.

This audit does not imply AG2 comparability or direct scientific superiority; independent MFASS-v2 official TEST remains unscored.
