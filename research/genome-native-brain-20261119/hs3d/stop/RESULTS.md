## Frozen experiment

Same 1,200 authentic HS3D human AG acceptor Train sequences for original supervised 4nt-viewport class learning, same 1,000 delayed native primitive-composition reward episodes (two original Brain physical genomic movements), then an additional original-Brain-native STOP/GO learner on up to 1,000 real calibration rows.

At each observation of a genuine 4-base genomic viewport, the original Brain's own P/N belief determines a native C6 sensor bucket. `Brain.predict([observed4,stageAndBelief,proposedSTOPorGO])` ranks native predicted reward for STOP vs GO. It receives no hidden destination bases, future feedback or ground-truth P/N until after actual completion. Only native `Brain.live` learns its realized STOP/GO experiences.

The same true labels are hidden on **400 development cases** that have already been used for historical exploratory research; NOT independent confirmation. Matched same-Brain forced-full budget, original one-view, random stop, and raw belief-margin threshold controls were evaluated read-only.

## Actual results

| Native organism gate learning | Native accuracy | Native macro-F1 | Mean true 4nt observations | STOP behavior |
|---|---:|---:|---:|---|
| No gate learning | 48.75% | 43.59% | **1.000** | always stops immediately, fails correctness |
| Actual P/N feedback with 5% extra observation cost | 69.25% | 66.88% | **3.000** | always continues, fails savings |
| **Actual P/N feedback without extra observation cost** | **63.25%** | **62.82%** | **2.7025** | stop after 1 view: 8, after 2: 103; all 3: 289 |
| Class-outcome reward destroyed | 52.50% | 40.10% | **1.46** | 308 cases stop immediately, fails correctness |

Matched SAME Brain after free-cost training and real gate feedback:
- native STOP policy **63.25% / 62.82% F1** at mean **2.7025** views;
- full physically permitted three views **60.75% / 59.88%** at 3 views;
- simple native belief-margin .8 stopping rule **61.25% / 60.45%** at 2.955 views;
- deterministic random STOP **59.50% / 59.45%** at 1.735 views;
- always stop one view **55.25% / 55.13%** at one view.

Relative native free-stop vs matched full: **+2.50 percentage points accuracy and +2.94pp macro-F1**, with `(3-2.7025)/3=9.9167%` fewer actual 4nt viewport observations. These are measured on already-used dev400; they are not new biological efficacy and no paired confidence interval was calculated.

**Important pre-registered outcome:** strict 15% observation savings threshold **NOT MET** (9.92%), even though class accuracy/F1 preservation and conditional nonconstant STOP choices passed. The cost-aware version stopped on **ZERO** test cases, so forcing a 5% penalty in original native binary reward did not induce useful stop behavior. This is a **PARTIAL NATIVE STOP CAPABILITY**, not a completed discovery agent.

At this stage any gain may partly arise because the original Brain's shared global `Brain.live` path also perturbs its P/N class distributions. Matched same-Brain full-budget controls separate action choice at evaluation but do not prove the stop gate's reward-specific effect independently of model-state interference.

## Scientific meaning and next genuinely different causal question

These experiments show the original Brain can have *nonconstant state-dependent STOP behavior* and can sometimes improve correctness by declining further observations. They also identify the failure of naive binary utility penalty: the native action reward needs a direct model of **the marginal value of a new observation**, rather than merely whether the final global P/N classification happened to be right.

A DIFFERENT next mechanism (not a parameter tweak): during training only, the original Brain can physically execute both STOP and CONTINUE branches, observe both actual predictions on real human DNA and experience which action **causally changes success**. It should learn to predict an expected relative improvement from prospective movement, then at inference commit to only one branch without reading the alternate destination.

This is a proposed active counterfactual experiment, not yet executed. Generic counterfactual policy learning exists in the literature; its global novelty is unverified. It must use the same original `Brain.live()/predict()` with no external trained actor, an explicit matched-exposure and destroyed-preference control, and no truth or unobserved nucleotides in action selection.
