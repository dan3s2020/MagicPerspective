# Braivour / MagicPerspective V42 — real HS3D human splicing research

**Date:** 2026-11-19  
**Evidence level:** real biological data, original native Brain, frozen independent developer-provided Test for *one fixed native mode*; later perspective-policy results remain exploratory.  
**Comparison to AlphaGenome 2:** **NOT performed; NOT beaten**.

## 1. Why this biological task matters more than the earlier UCI motif test

Earlier UCI 60nt classification produced 88% development accuracy after 2,408 training examples, **exactly identical to the GT/AG rule on each of 400 development records** and insensitive to shuffling the other 56 nucleotides. It was not evidence of long-range biology.

New real dataset: [EnsembleSplice HS3D balanced human splice sites](https://github.com/OluwadareLab/EnsembleSplice), commit `e04aa5aeb4035adac9ce6c65c2143c2ef7163332`. A 140nt sequence is labelled **true donor splice site (P)** or **false donor splice site (N)**. True and false candidates all retain **GT** at indices 70..71, verified on **1,400 training rows, 400 development rows and 1,100 official test rows** in our frozen protocol. Presence of GT alone cannot distinguish the two classes.

No synthetic DNA labels, fake GGUF donor, regenerated sequence functions, hidden answer route or separate classifier has been substituted for the real original Brain.

## 2. Original native V42 fixed-view experiment — confirmed official Test

Original Brain and native code imported unchanged from `v17/transcend/torus-aether/devour/brain.mjs`; original `Brain.live()` learns authentic examples, `Brain.predict()` classifies unseen sequences.

- **Original architecture:** native C cap4, A depth2, native original rules with `off:["R2","R3"]`.
- **Training:** 700 real true and 700 real false human donors (total **1,400**), exact original source Train. Labels entered original `Brain.live` only during training.
- **Sensory intervention:** retain all 140 nucleotides losslessly but place the four real bases at zero-index positions **72..75** immediately before the native decision. This perspective is **human-chosen from a pre-registered set** of 12 alternatives.
- **Selection:** maximum macro-F1 on **400 development rows** (200 P, 200 N). Winner frozen in [FROZEN_SELECTION_BEFORE_OFFICIAL_TEST.md](./FROZEN_SELECTION_BEFORE_OFFICIAL_TEST.md), commit `bd7817ff84ce595e554d16dd86576cdcce22b2fd`, before ever fetching the upstream official `Test` dataset.
- Development result: **83.50% accuracy; 83.2979% macro-F1**.

### Original official human HS3D Test

One-shot frozen official Test, **1,100 unseen rows**: 550 true and 550 false donor candidates, no exact-sequence overlap with source Train/Dev after deduplication.

This is a real signal **beyond mere central GT presence**. It is not evidence of using all 140nt for inference; the original native C decision is still directly based on four manually positioned downstream bases.

## 3. Strong non-native controls (honest scientific context)

Simple traditional positional log-odds matrices (Laplace=1, threshold=0) trained on the **same** 1,400 real HS3D training rows. These controls are **outside** the organism and are **never substituted** into its learning, actions, or inferencer.

| Model and information available | Official Test accuracy | Macro-F1 |
|---|---:|---:|
| Central GT only (true/false both GT) | **50.00%** | 33.33% |
| **Original native V42 Brain with 4nt view** | **79.18%** | **78.76%** |
| Position-wise PWM on the *same four* bases 72..75 | **84.55%** | **84.55%** |
| Position-wise PWM on 20 bases 60..79 | **91.18%** | **91.17%** |
| Position-wise PWM on all 140 bases | 80.36% | 80.36% |

**Interpretation:** original Brain adapts to a real biological distinction beyond mere GT, but it underperforms even a simple four-base PWM and is far behind the very simple 20-base PWM. We have **not** reached state-of-the-art performance. Note the 140-base PWM's inferior performance is about this training size, this model and data distribution, not a physical law that less input is always better.

## 4. A new native mechanism inside the SAME original Brain: viewpoint selection

A separate new experiment did not alter the original `Brain.live` or `Brain.predict`. It used:
- Same original V42 Brain and its original **`ConstructedPathLearner.learnTransferable()`/`transferableScore()`** as the action/reliability learning organ.
- The original Brain's own `brain.body` holds view state and action records; **`brain.constructedPaths.pathPolicy[6]`** contains the genuine learned policy parameters, updated only by real training/calibration feedback.
- Real 140nt HS3D sequence as navigable world with twelve **manually enumerated** four-nucleotide windows at positions `54,58,62,66,68,70,72,74,78,82,90,100`.
- Original C cap5 sees the true positional viewport symbol and four real bases; native Brain predictions are the *only* class predictions. During calibration the original policy gets the **real correctness feedback only AFTER its candidate predictions were formed**.
- It scans **all 12** allowed candidate windows before choosing one to trust; therefore this is **native learned perspective selection**, not yet limited-budget self-directed active vision. No unseen true label enters any prediction.

### First native policy test: negative finding

1,200 training rows, 200 calibration rows and 400 development rows from upstream **TRAIN only**, no official Test. Initial native all-window `ConstructedPathLearner` policy:
- `R2R3-native-path` selected policy **67.50%**, same trained original Brain fixed70 **76.75%**.
- `R3-native-path` selected policy **50.25%**, same trained original Brain fixed70 **36.25%**.
- Policy changed its native 6D weights after **2,400** full-information calibration outcomes, but **did not discover an improved viewpoint**. Negative result recorded, not disguised.

Source: [native policy protocol](./native-actions/PRETEST.md), [actual 2-mode JSON](./native-actions/results/learned-native-perspective-2-modes.json), [CI action](https://github.com/dan3s2020/MagicPerspective/actions/runs/44615103827).

### New causal intervention: native policy feedback and world geometry

New, pre-registered **different** training-only development protocol: same 1,200 native Brain training rows, 1,000 different calibration rows and a **new** 400-row development subset (indices 1,100..1,299 within source Train per class), with generic topological distance to the starting body position as an additional sensory feature.

| Same original Brain / same new 400 development rows | Accuracy | Macro-F1 |
|---|---:|---:|
| Fixed70 with same multi-window-trained native Brain | 77.00% | 76.87% |
| Fixed72 | 68.25% | 67.33% |
| Original native action policy, **one selected action** rewarded (bandit) | **78.00%** | **77.22%** |
| Original native action policy, all observed actions rewarded | **80.00%** | **79.84%** |
| Choice by raw original Brain confidence, no policy | 69.75% | 69.46% |
| Deterministic pseudo-random view | 59.00% | 58.93% |

The original native body policy received **1,000 actual updates** in the one-action feedback arm or **12,000 original-native updates** in the 12-view all-feedback arm. Both altered the original `ConstructedPathLearner.pathPolicy` and the selected view distribution. **This is a measured exploratory development improvement over fixed70, not confirmed on a new independent biological dataset.**

Importantly, the two positive arms have different feedback amounts by design. They do not isolate whether the improvement was due to longer calibration, the new physical topology feature, or their interaction. A separate [2-factor causal ablation protocol](./native-actions/FACTORIAL_ABLATION_PROTOCOL.md) and its real workflow address precisely that question.

## 5. Why it matters scientifically

### Positive findings
1. The native organism learned a **real biological distinction** between true and false human splice donors that all have central GT, measured on official developer-provided Test.
2. Original native A/C architecture flags `R2` and `R3` substantially affected measured biological performance: unmodified default R3 68.75% vs original native R2/R3-off 83.50% development in their respective fixed-view modes.
3. A genuine original Brain-owned perspective policy trained from historical outcome feedback can improve the same organism's development accuracy **relative to a fixed view in the same multi-window learning experiment** (80% vs 77%).
4. Weak outcomes, including failed native policy and extra false positives, were explicitly preserved rather than rebranded as successful discoveries.

### Significant limitations
- Candidate views **hand-specified**. No autonomous arbitrary region discovery or long-range regulatory hypothesis has been demonstrated.
- All 12 windows are scanned: the observed accuracy is not evidence of limited-observation active exploration efficiency.
- A conventional 20-nt PWM **significantly outperforms** the native 4nt organism on official human donor Test (91.18% vs 79.18%).
- The native 80% perspective-policy number is **development-only**, and the older donor official Test has now been seen at a project level. It cannot serve as a new pristine test for later tuned native policies.
- HS3D is a single historical human genomic dataset with incomplete gene-family metadata; exact duplicate exclusion is not proof of homology-independent generalization.
- No human tissue-conditioned gene expression, causal variant-effect score, reference/alternative variant functional change, AlphaGenome 2 call, low-compute superiority or clinical utility has been demonstrated.
- Multiple R2/R3/viewport modes were screened; exploratory wins can reflect method selection.

## 6. Next strict scientific gates

**Gate A:** Confirm the native feedback/topology improvement with causal 2×2 ablations and avoid repeated score-chasing on the same development subset.

**Gate B:** Test *the same original Brain* on a genuinely different observed biological process (for example **true vs false acceptor AG** at the human splice boundary, measured in an upstream **uninspected test set**) with a pre-registered evaluation; distinguish from-scratch, donor-state transfer and few-shot reuse. Do **not** claim cross-domain transfer until a donor-trained Brain is actually preserved and compared to a fresh original Brain.

**Gate C:** Develop true native action budget: the original organism must select which region to observe before seeing all candidate windows, through its own persisted action and feedback dynamics, with label hidden. Compare with matched fixed and random observation budgets; no hidden goal or prefilled correct route.

**Gate D:** Move to real measured reference/alternative variant splicing effects with tissue metadata and a matched official AlphaGenome 2 baseline. Only then can a scientifically honest AG2 comparison even begin.

**Scientific status:** encouraging original-organism adaptation and preliminary feedback-driven viewpoint selection, **NOT** a breakthrough superior to modern genomics methods. All original working code and user donor-training checkpoints remain unchanged.

## 7. Measured causal factorial: native geometry prior vs quantity of calibration feedback

We preregistered an ablation in [FACTORIAL_ABLATION_PROTOCOL.md](./native-actions/FACTORIAL_ABLATION_PROTOCOL.md) and ran it on original real human HS3D TRAIN-derived development data, **without the official Test checkout**. The frozen 400 development examples, original C5 Brain, 12 physical views, R2/R3-off rules, original learning code and input labels were identical across all four cells.

| Original native pathPolicy feature | 200 calibration examples | 1,000 calibration examples |
|---|---:|---:|
| Observed four-base **nucleotide diversity** | 73.00% accuracy / 72.29% macro-F1 | 74.75% / 74.75% |
| **Physical topology / distance** to known window center70 | **81.00% / 80.56%** | **80.00% / 79.84%** |

Same original Brain **fixed70** readout: **77.00% accuracy / 76.87% macro-F1** on the same 400 development sequences. At 200 historical feedback examples, adding the explicit topology representation changes native policy accuracy from **73% to 81%**; at 1,000 feedback examples, from **74.75% to 80%**. Increasing feedback from 200 to 1,000 does **not** improve the topology case here (81% -> 80%).

**What is causally tested:** geometry feature and calibration-amount interventions inside the original `ConstructedPathLearner`. **What is not established:** statistical significance under an independent external test, automatic discovery of biological coordinate70, long-range regulatory explanation, or superiority to standard 20-nt PWM. The topology feature was human-defined as distance from the known splice boundary; the organism **learned how much to trust it** from observed action rewards. This is not independent invention of the coordinates.

**Data integrity caveat:** in initial instrumented JSON the `calibration.rows` field reports **available** pool size (1,000) for all variants; the true **consumed** calibration number is the `calibrationAmount` field, or the original learned update count/12 for full-feedback mode. This is an instrumentation label issue, not a training/evaluation count discrepancy. Actual consumed amounts were 200, 200, 1,000 and 1,000 respectively, with original `ConstructedPathLearner` receiving 2,400 or 12,000 feedback updates.

- [Causal factorial measured JSON with disambiguated effective counts](./native-actions/results/topology-vs-amount-factorial-real.json)
- [Original successful factorial workflow](https://github.com/dan3s2020/MagicPerspective/actions/runs/44616476817)
- Fourth comparison arm [original native 1,000-feedback topological policy](./native-actions/results/bandit-versus-allviews-topology-real.json)

**Overall interpretation:** we identified a reproducible exploratory change in how the original organism chooses among biologically real windows; explicit physical context helped more than extra calibration examples in this factorial. **No AlphaGenome 2 comparison or novel human genetic law is demonstrated.**

## 8. Source/experiment status

All previously functioning MagicPerspective/Braivour versions and user checkpoints are preserved. This research was carried out on isolated branches, and each CI job used the original native V42 Brain and actual pinned human genomic sequences. The official HS3D donor Test is now *historically observed* and must not be reused as a fresh unseen final benchmark after further method changes.

To make a defensible next claim of transferred intelligence, a donor-trained *identical saved native Brain and policy* must be tested on the **different** HS3D acceptor AG task against fresh-from-scratch and matched-shot controls with a new frozen protocol before examining acceptor official Test.
