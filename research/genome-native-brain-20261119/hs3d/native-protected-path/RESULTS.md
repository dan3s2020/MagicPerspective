## What was actually novel, and DID succeed

The previous five-mode one-Brain experiment proved that teaching the same `Brain` genomic action rewards using a shared `Brain.live` next-symbol stream **changes its C8 class memory** (mask exact:149 → fold:131 etc.), damaging the already useful paired DNA classifier. This investigation used the **original `brain.constructedPaths`** member which exists in every original Brain: its original `ConstructedPathLearner.learnTransferable` and `ConstructedTransitionGraph.links.observe` memorized delayed success/failure of actual bodily primitive movements. The original native `LeanC` class learned only genuine P/N examples, and receives NO reward tokens. These are not separate models instantiated outside original Brain.

Genuine 140nt human HS3D acceptor AG P/N from pinned original source, 1200 unique real supervised train examples, **two distinct fully genuine paired physical DNA viewpoints** (70+64 and70+66), each with 8 true genomic bases+P/N+newline, **24,000 native Brain.live symbols**. Then 1000 original real physical action episodes with 25% deterministic exploration, **2,000 original path/graph updates** for each of the true-reward/destroyed-reward arms. The SAME Brain physically executes two legal primitive movements and predicts P/N with true first4+actually reached final4 in native C8. Frozen dev400 data previously examined; NO independently blind test run.

**CORE successful native non-regression invariant:** original class memory remained *exactly the same* before/after path learning: original Brain.lived **24000 →24000**, C8 learned episodes unchanged **24000**, native active selected mask **exact:165 → exact:165** for all 3 arms. Both feedback arms changed genuine original ConstructedPathLearner weights and added 2000 observed original graph edges. This was NOT achieved by the previous shared global reward stream.

**CORE learned behavior:** true rewards make original Brain choose **nonconstant real physical trajectories conditioned on viewed DNA**, including `new > new`, `left > new`, `new > open`, `again > left` etc. Frozen dev positions **64 in231/400, 66 in118/400, 70 in51/400**. Broken-reward graph chooses mainly70 and lower accuracy, confirming the genuine delayed consequence matters.

## New mechanistic blocker (not a repeated old failure)

Original C8 classifier receives true start70 four nucleotide bases + true final four nucleotide bases, but when **different true physical destinations64 and66** are trained under this same eight-character code, the Brain never sees *which coordinate* produced the final four. It can therefore conflate conflicting evidence from nonidentical genomic positions even when its original path memory is perfect. Native mask exact:165 differs from earlier fixed64-specific exact:149, and single model fixed64 performance fell 74.75% →69.00%. This is a **plausible representational ambiguity**, not yet proven as causal; merely increasing C9 context size could fail or worsen results.

A distinct precommitted separate study at `research/HS3D-NATIVE-POSITION-C9-20261121` tests original `Brain` native C9 with **one authentic body-position symbol plus all eight genuine bases**, versus same-capacity missing-tag and randomized-tag controls, to see if coordinate identity truly resolves the ambiguity. This is NOT a blind search over random seeds.
