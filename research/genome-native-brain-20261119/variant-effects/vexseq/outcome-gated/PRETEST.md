## Motivating mechanistic source-level observation
In genuine earlier native Vex-seq work one original Brain saw 8 REF/ALT/cell/position symbols then one measured effect label and one newline. Its untouched `LeanC.observe` trains C on ALL TEN next-byte positions of the sequence; **nine in ten C observation events are not measured biological outcomes**. Its native `LeanC.reframe` selects C perspectives based on next-byte validation across ALL training characters, rather than a meaningful biological effect outcome. The observed original selected C exact masks omitted joint context variables (K/H identity, mutated ALT base or offset). This is not definitive proof of whole-Brain limitation: A's may contribute. Source of same original brain: `v17/transcend/torus-aether/devour/brain.mjs` and `lean-c.mjs`.

## Mechanism: original one Brain + native C moment gating, not substitute classifier
Existing `Brain.live` receives EVERY original real source DNA symbol and original true K562/HepG2 experimental class/newline, identically in all arms. Original `LeanC.observe`, `LeanC.reframe`, `EmergentChain`, `EmergentA` and `Brain.predict` implementations remain intact. The new runner changes *when* the existing `brain.e.c.observe(ctx,y)` is permitted to run through a per-instance gating adapter, never its formula, next-byte target, candidate dictionary or class-specific weights:
- `global-true-first`: original C.observe always receives all ten observation moments; real cell K/H as FIRST symbol in 8-symbol genetic observation.
- `outcome-true-first`: native C.observe ONLY receives the true biological outcome moment (the +/0/- after eight actual DNA/metadata symbols). The *same Brain* and its A organs still live every real input and real target/newline via original Brain.live, exactly 10 bytes per case.
- `outcome-true-last`: same moment gating, cell identity is LAST of 8 source-true symbols, no loss of REF/ALT context.
- `outcome-blind-last`: same moment gating with constant X in place of cell K/H, same actual labels, same native byte budget.
- `alt-only-true-last`: matched-count negative control: native C.observe ONLY at the **ALT mutated nucleotide moment** (the 7th input byte with cell last), never outcome moment. It learns the same number of original C moments but a different biological target. Original Brain.live still learns all true labels. Comparing this against outcome-true-last controls for fewer C updates alone.

**Crucial scope:** This gates the selected native C organ's observations, which ALSO changes the predictions from C that are used inside the original A/chain during later learning. It therefore is an *integrated native learning-schedule intervention*, NOT a perfect selective ablation of C without any side effects. It creates NO second classifier, no new Brain object per cell, no fake DNA or desired path, and no invented biological labels.

## Additional read-only native candidate-pool intervention (CALIBRATION ONLY)
After training, leave native Brain state and candidate tables untouched. First evaluate `brain.predict` using original self-selected C active. For gated modes also make a calibration-based **native candidate perspective selection**, the choice of native C active `exact:mask` or `fold:mask` (candidates() from original engine, **NOT a new predictive head**):
1. Only original C masks that jointly observe real ALT base, mutation offset, real K/H identity, and at least one real REF base (all token positions verified via original Brain.ctxOf() reversed order); for blind-X mode the identity token is physically present but constant, so no claimed cell specificity. Candidate masks enumerated from ORIGINAL `candidates(8)`, no custom extractor.
2. Candidate readouts from original `distC` at real CALIBRATION cases, measuring 3-way measured effect labels. Choose by greatest CALIBRATION macro-F1; tie by balanced accuracy and ascending ID. The original C.readout alone is the selection feedback; original `Brain.predict` with this frozen active C candidate is the actual DEV biological predictor (native A chain still applied).
3. Repeat the same selection with **deterministically permuted calibration truth**, keeping genuine training and C native weights unchanged, as an explicit non-biological negative CONTROL. It is never fed into Brain.live or used as a true experimental label.
4. For global/alt-only non-outcome controls, the same perspective-selection process is permitted, to isolate effects of biological outcome gating versus external perspective selection. All arms have same possible native candidate masks, calibration samples and predictions.

When comparing to earlier original results, note reducing source Train 77→67 events changes sample size, so ONLY within THIS identical split is causal. Genuine K/H labels from CALIBRATION are visible to the *external scorer* selecting among original native candidates but never used to update weights. Hence an improvement would demonstrate a human-designed outcome-calibration + original-native C gate, NOT autonomously invented learning goals.
