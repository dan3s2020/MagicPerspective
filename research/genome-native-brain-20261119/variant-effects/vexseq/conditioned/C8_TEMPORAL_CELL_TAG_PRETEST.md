# Pre-frozen C8 native temporal position of genuine cell identity — original Brain
2026-11-22. This experiment is committed before seeing actual DEV cell-conditioned first- vs last-tag outcome metrics.

## Distinct causal motivation
In the previous actual 4-mode original-native *aggregate* Vex-seq effect benchmark, original C9 real-distance token was the EARLIEST of nine observed bytes, and selected native C9 exact:89 does not explicitly read that earliest (reversed lag8) bit. Genuine positional metadata failed to help. This suggests the original `LeanC` masks may ignore biologically important domain identity if the token is too far from the final prediction.

In a new separate honest K562/HepG2 outcome task we already preregistered native C8 lossless genotype encoding + cell tag FIRST. Here test the **same biological information, same original Brain, same cell-specific labels, same 26,060 original live symbols**, but change *only input temporal placement of cell identity*.

## Identical frozen design
Same exact original source `Vex-seq@36d9c4a6e5e74def46b3cada69d3166f08c54bd5`, real 1960 one-base pairs, partitions TRAIN1303 variants across77 original events/DEV390 variants across16 events, original final267 stays unscored. True lab effects `delta_psi_K` (K562) and `delta_psi_H` (HepG2) threshold ±5 percentage points fixed. Original unchanged V42 `Brain.live` and `Brain.predict`, C8, R2/R3 off, seed20261122, 2606 lived K/H examples, identical original variant SHA order and K then H.

Same eight lossless input tokens: four real REF bases; true ALT base; true within-four-base mutation position; true splice distance bin; actual cell K or H (or constant X). The ONLY intervention is the order of those symbols:
- earlier existing `condition-true`: `[K/H, spliceBin, offset, ref0,ref1,ref2,ref3,alt]`.
- earlier existing `condition-blind`: `[X, spliceBin, offset, ref0,ref1,ref2,ref3,alt]`.
- **new** `condition-true-last`: `[spliceBin,offset,ref0,ref1,ref2,ref3,alt,K/H]`.
- **new** `condition-blind-last`: `[spliceBin,offset,ref0,ref1,ref2,ref3,alt,X]`.

Classes, genome sequence content, training exposure and native mechanisms unchanged; no external classifier or hidden desired action. DEV classification of 780 true labeled K/H observations, macro-F1 primary, per-cell metrics, paired true-disagreement recall, same-blind and swapped-cell-token controls. The official 267-final-event test remains untouched and locked until a separate winner/negative decision is committed. This is exploratory because original dev aggregation scores were previously inspected.

**Meaningful positive**: same actual native Brain with a visible last cell token predicts different outcomes for the SAME variant correctly in both K/H conditions significantly more often than with FIRST token or constant tag, and beats independent simple source-statistical controls. Merely flipping predictions with a wrong tag is not sufficient: must improve actual measured labels. The signal would establish useful conditional sensory placement, not automatically discovered biological structure or AlphaGenome2 parity. Negative outcome also must be recorded.
