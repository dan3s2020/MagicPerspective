# ONE-SHOT FROZEN 17-event Vex-seq confirmation: original V42 Brain outcome-specific C mask
Date 2026-11-22. This exact method and all controls are **committed before ANY original Vex-seq FINAL variant effect is scored by this method**. Never tune from final.

## Mechanism already selected on prior development (not on final)
Real measured K562/HepG2 ΔPSI of 1960 verified original REF→ALT single-nucleotide mutations, pinned `scottiadamson/Vex-seq@36d9c4a6e5e74def46b3cada69d3166f08c54bd5`. Original dataset partition held 77 source events (1303 variants) for train/calibration, separate 16 source events (390 variants) for exploratory DEV and **separate 17 source events (267 variants) for this exact one-shot FINAL confirmation**.

We measured a positive but SMALL exploratory signal on actual DEV390 × 2 true K/H cell measurements (=780):
- Same one original V42 `Brain` with `LeanC` source unchanged. Native C learned **ONLY at actual outcome-label moments**, while original Brain and native A lived every true source DNA, effect outcome, newline.
- SOURCE TRAIN: from original 77 TRAIN events, 10 are withheld for choosing native C perspective on TRUE source effect labels; remaining **67 events, 1,117 unique genuine REF/ALT variants (2,234 true K/H examples)** train the original Brain. SHA group/order salts frozen in [original protocol](../outcome-gated/PRETEST.md).
- ORIGINAL eight-symbol lossless REF/ALT genotype with real K/H cell identity as FIRST symbol: `[K/H, spliceBin, 0..3 mutationOffset, REF0,REF1,REF2,REF3, actual mutated ALT nucleotide]`. Measured outcome class is based on ±5 percentage-point `delta_psi_K/H` as originally published. Each authentic observation gives 10 original Brain.live symbols, original C sees exactly one outcome moment (2,234 original C.observe labels). Single Brain, C8, A depth2, R2/R3 off, seed20261122, same source ID ordering.
- EXACT chosen original native `LeanC` model: **`exact:175`** (original `candidates(8)`), native mask bits 0,1,2,3,5,7 = actual `[ALT,REF3,REF2,REF1,mutationOffset,K/H]`; choose this candidate on heldout independent 10-source-event CALIBRATION by actual full original `Brain.predict` after native A and final chain, not by isolated C or post-hoc FINAL labels.
- Actual prior complete development evidence: [full-chain run](https://github.com/dan3s2020/MagicPerspective/actions/runs/45056569574), job `outcome-true-first`; DEVELOPMENT 780 actual cell observations: full-chain native candidate **macro-F1 35.7304%, accuracy 58.0769%, and 6/91 original variants with different measured K/H outcomes predicted BOTH correctly**. Same original Brain self-selected perspective `exact:72` macro-F129.8752%, and calibration label PERMUTED selected native `exact:235` macro-F133.3869%. Non-neural source-only mutation+position+cell lookup macro-F1 34.3230%. Therefore the chosen method beat that same DEV baseline by only **1.4074 F1 percentage points**, not remotely proof it beats AlphaGenome 2.
- The original *C-only* calibration selected a different native mask `exact:231`, DEV F1 29.48%. This previous direct negative comparison shows the full original Brain outcome should determine perspective choice, not C-only score.

## Frozen final confirmation and absolutely no re-selection
- **NO candidate search based on final!** Re-run the exact original native training on the same genuine 1,117 variants/67 events; the original native full-Brain CALIBRATION again must select `exact:175` on the same 186 unique CALIBRATION variants (372 K/H labeled cases). It is a deterministic reproducibility assertion only; if mismatch or source hash changes, FAIL CLOSED rather than silently selecting another mask.
- Confirm original auto-selected C still `exact:72` and independently calibrated negative-control shuffled-truth C still `exact:235`. These are FROZEN predeclared readouts and may not change on final.
- Original C masks are changed ONLY as a read-only `brain.e.c.active` setting, calling unchanged `Brain.predict` and restoring active afterward; original actual C and A weights never get final labels.
- Score each of **exactly 267** completely heldout original Vex-seq variant groups (17 biological source events) in BOTH **K562 and HepG2** =534 genuine original lab outcomes, same as original DEV evaluation except group identity.
- Three predeclared native readouts from one trained Brain: `exact:175` frozen true outcome calibration (PRIMARY), `exact:72` native original self-selected control, `exact:235` shuffled calibration native mask negative control. The default selected on FINAL may not be changed.
- Primary independent evaluation: original 3-class (0/−/+) macro-F1 across 534 condition-measured examples. Secondary accuracy, balanced accuracy, strong positive & negative precision/recall and confusion, native score Spearman vs continuous K/H ΔPSI, number of variants with real differing K/H labels predicted BOTH correctly, same-readout swapped-cell token control.
- Exact matched non-neural baselines calculated ONLY from 1,117 original TRAIN variant observations: always-neutral, source original mutation/substitution + splice distance + K/H cell category contingency with simple Laplace pseudocount1. No alternate task and no external future model score.
- Predeclared event-cluster uncertainty: 2000 deterministic bootstrap repetitions sampling exactly17 original heldout source-event IDs with replacement, carrying all K/H mutations within each sampled event. For each replicate calculate `macroF1(native frozen exact175) - macroF1(original empirical substitution-distance-cell)`. Report 2.5/97.5 percentile bounds and the fraction of replicates with improvement <=0. Only supplementary inference, given only 17 events.
- Compare true-cell conditional discrepancy. In previous DEV, 91 genuine pairs had different effect classes. In FINAL report actual number of such pairs and BOTH-correct by model. Do not force artificial balancing of FINAL.
- Original source is a mini-gene reporter assay, not whole chromosome or adult tissue state. Family/homology grouping is unknown. More stringent distinct-source tests required for biology generalization.

## Success/failure gates fixed pre-result
1. Correctly predicted both cell-specific experimental effects for a nontrivial number of variant pairs with genuinely discordant K/H truth, and detect SOME real strong positive and negative effects.
2. PRIMARY native macro-F1 genuinely above same-source actual empirical baseline on **untouched FINAL**; if delta <=0 or event-bootstrap CI includes0, report **inconclusive or failure**, not proof of superiority.
3. The frozen native mask must outperform its actual shuffled-calibration negative control, not just be a lucky genotype/cell classifier.
4. No additional final resampling, no label-driven retuning after scoring, no cherry-picking favorable novel output readouts. A technical infrastructure error may be retried with exactly the same frozen code/hashes; valid completed output is final.
5. Even if all conditions pass, this only tests **267 real measured Vex-seq variants**, and is **NOT** a head-to-head AlphaGenome 2 benchmark, which would require official full-genome model predictions on identical inputs/cell conditions and identical metrics. AG2 API outputs may not be used to train any model under its terms.

No changes to original V42 Brain, Braivour, active user checkpoints, previous running native models, or any previously documented historical experiment.
