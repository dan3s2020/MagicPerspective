# Pre-frozen mechanistic correction: select native C perspective by actual FULL original Brain outcome, not only C-alone output
Date 2026-11-22. Committed BEFORE any full-chain candidate-selection run or variant-effect predictions made under this intervention.

## Historical measured observation, not a hoped-for number
The immediately preceding real Vex-seq 5-arm experiment on genuine K562/HepG2 variant effects used unchanged original V42 Brain, target-gated original C and a FULLY SOURCE EVENT-DISJOINT calibration set of 10 source events; candidate native C perspective masks were scored on original `distC` output only, while final dev predictions came from original `Brain.predict` -> `EmergentChain.play`, which also includes original A pathways and backward R3-disabled averaging. Source: `v17/transcend/torus-aether/emergent.mjs` `play()`, and `torus.mjs` `distC()`.

The actual calibrated C candidate in original first-cell layout scored only ~29.48% DEV macro F1, while a control candidate selected by intentionally SHUFFLED calibration truths unexpectedly scored 35.73% F1 and correctly distinguished BOTH cell-specific measured outcomes of 6/91 discordant DEV variants. This does not demonstrate learning: shuffled control performed better than authentic-label selection. A clear mechanistic explanation is that selecting for C's solo output misaligns the actual target, which is the entire Brain's final output after A pathways. This study tests the explanation directly.

## Exactly ONE changed mechanism
Keep *all source, chronology, V42 Brain code, C model, A model, 10 event calibration / 67 event training / 16 event dev groups, input layout, seed, equal symbol/label budgets, moment-gating intervention, native-candidate masks, baseline and scoring rules* identical to the original [outcome-gated pretest](../outcome-gated/PRETEST.md).

The ONE intervention: when calibrating candidate `brain.e.c.active` masks on actual K/H measured effect labels, score the **original FULL `brain.predict(stimulus)`** after A/chain/R3 merge, rather than `distC` alone. In each calibration candidate, set only the EXISTING `brain.e.c.active` to a permissible ORIGINAL C8 candidate, call unchanged `Brain.predict()`, score the output distribution restricted to the predeclared 3 valid class bytes; restore active afterward. `Brain.live` must never receive a calibration example or test label and source `Brain` implementation stays unmodified. No replacement predictor, no new head, and no injected desired path. The outer *choice* among 60 native candidates is a human-authored calibration mechanism; it is NOT a newly evolved internal objective, and claiming autonomy would be false.

As previously preregistered, the only permissible source-real C candidates are original `candidates(8)` from `engine.mjs`, `exact/fold` masks jointly seeing cell input token, source-real ALT mutation base, true within-4nt mutation offset and ≥1 real REF base. Original source reverse-history `Brain.ctxOf()` mapping is checked. Exactly 60 candidate programs in all arms, no trial of external trained model, no adjustment after dev evaluation.

## Five original native modes and controls
Same five modes as original comparator:
- `global-true-first` — original C observes all 10 per-sample bytes, real K/H identity FIRST;
- `outcome-true-first` — original native C.observe only authentic outcome label, K/H FIRST;
- `outcome-true-last` — original C.observe only outcome, K/H LAST;
- `outcome-blind-last` — original C.observe only outcome, constant X last, full real measured labels;
- `alt-only-true-last` — matched-count native C only observes original mutated ALT base, label hidden from C itself.

Original Brain and native A organs live all actual eight allele symbols + genuine K/H measured class + newline, exactly the same 10 symbols per case in every mode, and calibration + dev never teach any new symbols.

Readouts per mode: native self-selected C, calibration-selected native C using **real full-brain outcomes**, and same full-brain method with systematically permuted calibration truth as negative control. All evaluated on same original DEV390 variants×K/H=780 measured conditions and 16 original biological source events, which have been examined historically (thus EXPLORATORY, never independently pristine).
