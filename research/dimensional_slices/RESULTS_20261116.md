# 2026-11-16 — Original V17 organism, A/C perspectives and real dimensional cross-sections

## Scope and user request

This experiment is NOT a standalone neural predictor and does NOT modify any running release, unrelated experiment, checkpoint, GGUF donor, main branch, or existing interface. The same existing original V17 `Brain` and `Discoverer` serve as agent, actuator and persistent learning memory. Authorizing user quotes, verbatim, are preserved in `user-intent/changes/2026-11-16-AC-SLICES.json`.

The world is an actually rotated 4D tesseract. Its 32 real 4D edges are intersected with `w=h` at 5 levels to make 3D cross-section points. Two genuinely different 2D projections produce A and C sensory readings. 25 *unseen* 4D rotations serve as independent frozen evaluation objects. This is the physical-geometric exercise, NOT the user's hypothesized intelligence structure ("target").

## Executed sequence — not planned or simulated metrics

### Experiment 1: unchanged original Brain bytewise A → unknown C

- Implementation: `native_ac_pairing.mjs`
- Actual GitHub Actions: https://github.com/dan3s2020/MagicPerspective/actions/runs/43769970185
- 30 training 4D orientations, 150 observed pairs; 25 unseen orientations, 125 heldout pairs.
- Native matched vs mismatched: **63.0% vs 63.0% cell accuracy**.
- A-copy: **63.2% cell accuracy**.
- **0% exact full images, 0 F1 for actual occupied geometry**.
- Verdict: FAILED to learn geometrical relationship. It learned the majority background.

### Experiment 2: original native Discoverer actually moves between dimensional cuts

- Implementation: `native_ac_action_world.mjs`
- Actual GitHub Actions: https://github.com/dan3s2020/MagicPerspective/actions/runs/43770663499
- Original `Brain.disc.choose` acts on a real physical section world, `Brain.disc.learnStep` feels its own movements, `Brain.live` senses consequences.
- 319/320 training goals reached; native body recognized itself (kind 3).
- Frozen heldout action consequences: **580**, physical motor movement prediction **100%**, goals reached **100%**.
- Geometry F1: **0**, matched-vs-scrambled cell accuracy both **61.864%**.
- Verdict: ORIGINAL BODY LEARNED ACTUATION AND GOAL NAVIGATION, but NOT geometric form transformation. Do not call these goal successes 4D reconstruction.

### Experiment 3: action-caused sensory transformations are LIVED in the original organism

- Implementation: `native_ac_lived_form.mjs`; geometry from `physical_sections.mjs`
- Actual GitHub Actions: https://github.com/dan3s2020/MagicPerspective/actions/runs/43771560041
- New mechanism: `Brain.disc.nativeSliceEffects` lives as the SAME original organism's native motor-sensory memory (no independent trained model or replacement `Discoverer`). Each causally executed movement logs real before/after geometric sensor co-changes. Before the **next** physical action is executed, the original organism's learned motor effect supplies its expected next perspective/level and its native causal sensor-memory predicts the full 16-cell visual pattern.
- Both brains: **960 training episodes** (959 reached goal). Identical original native motor physics; one gets physically correct A/C consequences, the other sees independently mismatched C evidence.
- Heldout: **25 independent new 4D orientations**; **562 strictly moving** physical action consequences, never counting stillness as successful visual prediction. Frozen test never learns from heldout consequences.

No systematic A/C-specific advantage is established for changing depth without switching perspective. Same-view transformations can gain against an untrained copy baseline yet also be learned when C is scrambled, so are NOT evidence of cross-perspective identity discovery.

#### Independence and statistical check

The **25 unseen rotation seeds**, not 562 correlated observations, are the statistical units. The script performs a deterministic 6,000-draw **cluster bootstrap** and 6,000-draw **paired object sign-flip test** on F1 differences between the two identically initialized original-body conditions.

| Independent-unit contrast | Paired F1 benefit | Cluster bootstrap 95% | Approximate sign-flip p |
|---|---:|---:|---:|
| A ↔ C, both directions | +3.885 pp | [+1.492, +6.373] pp | 0.00583 |
| A → C only | +2.574 pp | [+0.441, +4.582] pp | 0.03349 |
| C → A only | +5.196 pp | [+1.699, +8.628] pp | 0.01116 |

**Interpretation:** The original native organism's action-linked memory contains information specifically about correspondences between A/C perspectives that is measurably degraded when the perspectives are mismatched. This is the first positive *form-prediction* outcome of the three implemented stages, rather than only native motor learning or majority-class guessing. The improvement is small in absolute terms. Multiple tests and research choices make the p-values **exploratory**, not definitive; confirmation needs other shape families, pre-registered scoring and independent sensory levels. Whole geometry recovery remains essentially unsolved.

## Crucial boundaries / scientific falsifiability

1. The world itself has programmed 4D tesseract physics, not programmed solutions, labels or routes for the organism. The native Brain does not receive object identity, latent 4D coordinates, hidden next sensory values or an oracle action.
2. The A/C two-view rasters are only 4×4 and lose most geometric information. A single view generally does **not** determine the exact full 4D shape. Exact shape reconstruction is not achieved.
3. The 4D section is a genuine mathematical hyperplane intersection; this does **not** imply all five Platonic solids are literally the same 4D object.
4. Nothing here demonstrates physical quantum entanglement, intelligence-field discovery, GPT/GGUF intelligence assimilation, realistic 3D optical refraction or general language transfer.
5. The addition `nativeSliceEffects` is an experimental *new causal sense memory inside the original Discoverer*, not a claim of globally novel mathematics or a substitute classifier. Current motor and predict implementations are preserved.
6. Test correctness and success of the workflow must not be confused with proof of a general higher-dimensional cognition mechanism.
